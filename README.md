# Biblioteca Digital UniFECAF — Projeto de Design Web

Projeto acadêmico demonstrativo construído com HTML e CSS, seguindo as seções indicadas no protótipo do enunciado. Também serve como portfólio do trabalho de faculdade.

## Estrutura

- `index.html` — estrutura semântica e conteúdo da página.
- `style.css` — cores, tipografia, layout, estados de interação e regras responsivas.
- `imagens/` — ilustrações SVG criadas para o projeto e capas ilustrativas de livros.

## Como visualizar

Abra `index.html` em um navegador. Para publicar, envie a pasta do projeto para um repositório GitHub e ative o GitHub Pages, ou publique a pasta em outro serviço de hospedagem estática.

## Observações

- A página é uma primeira interface estática, sem backend ou pesquisa integrada ao acervo institucional.
- Os títulos, capas ilustrativas e textos sobre recursos demonstram a organização visual; não confirmam disponibilidade real na biblioteca UniFECAF.
- Os links de consulta apontam para buscas públicas na Open Library.
- A fonte DM Sans / Manrope é solicitada pelo Google Fonts; existem alternativas locais caso o serviço não esteja acessível.
- `trabalho-html-e-css` é o nome do repositório acadêmico e de portfólio do projeto.
